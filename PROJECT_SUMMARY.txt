🎯 5 SETUP STEPS (SUMMARY)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. IMPORT DATABASE (5 min)
   - Laragon → Database → HeidiSQL
   - Create: bangun_impian
   - Import: database/bangun_impian.sql

2. CONFIGURE .ENV (2 min)
   - Edit .env file
   - Fill DB credentials

3. GENERATE KEY (1 min)
   - php artisan key:generate

4. SETUP VIRTUAL HOST (5 min)
   - Edit hosts file
   - Add to httpd-vhosts.conf
   - Restart Apache

5. TEST & LAUNCH (3 min)
   - php artisan serve
   - Open: http://127.0.0.1:8000
